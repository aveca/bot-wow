What you can actually use

The page describes an information companion. It does not describe a program that plays the game.

Spots you write down

The intended companion is a notebook of places you choose. Nothing here watches the game and records them for you.

A route you follow

The planner orders stops. You walk the route yourself. The browser demo runs that ordering on simulated data.

Notes, not inputs

A future catch notebook would store what you type. No addon is offered today, including any addon that would play the game.

Not for sale yet

There is no deliverable compliant product, so there is no price, no checkout and no download.

How the planner is meant to be used

Three steps you do yourself. The browser demo lets you inspect the ordering without installing anything.

1. Note a spot

You record a place. The demo uses simulated coordinates. It does not read a game client.

2. Read the order

The planner proposes an order of those spots. You can try the same planner in the browser on simulated data.

3. Fish yourself

You follow the route. The product does not send clicks and does not move a character.

FAQ

Questions essentielles.

Le paiement est-il actif ?

Non. Aucun secret ni paiement réel n’est embarqué dans le MVP public. Mollie viendra côté backend/API.

GitHub Pages suffit-il ?

Oui pour le site vitrine statique. Pas pour une base de données, une authentification ou des webhooks : ces briques auront un backend séparé.

Et l’addon WoW ?

Le site sert de compagnon. Les actions réellement exécutées dans WoW devront être confirmées par le client et l’environnement de jeu.

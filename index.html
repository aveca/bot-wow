05 · FAQ

Les réponses.

Le site peut-il fonctionner seul ?

Oui pour la présentation et le parcours MVP. Les fonctions qui nécessitent WoW ou un serveur restent signalées comme dépendantes de leur intégration.

Le paiement est-il déjà actif ?

Non. Aucun paiement réel n’est simulé. Mollie sera intégré côté serveur lorsque l’API sera prête.

Pourquoi GitHub Pages ?

Pour garder un frontend simple, public, versionné et déployé automatiquement par GitHub Actions.

Quand bot-wow.com sera-t-il utilisé ?

Plus tard. Le MVP ne dépend volontairement d’aucun domaine personnalisé.

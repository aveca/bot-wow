What the fishing role actually ships

These four points come from the module register. They have tests. Inventory, navigation in game, grind and scripting are not included in this sale.

Bite to click, measured

The cast, bite and catch cycle is instrumented. The logged median from bite to click is 308 ms.

Spots it remembers

Spot memory is persistent: migrations, atomic writes, export and import.

A round you can inspect

The planner uses nearest neighbour plus 2-opt on measured legs, in three modes. The browser demo runs the same rules on simulated data.

Outside the game process

Windows background capture with PrintWindow, clicks as window messages, stop with F9. No process injection.

How it works

Three steps, all outside the game process. The browser demo lets you inspect the planner without installing anything.

1. Read the window

A runtime addon observes game state. The client captures the window as pixels. It does not read process memory.

2. Choose the round

Saved spots and the planner propose an order. You can try the same planner in the browser on simulated data.

3. Click as a window message

The click is sent to the window, not injected into the client. F9 stops the run.

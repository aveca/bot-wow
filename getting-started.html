Getting started

From download to first catch. The full illustrated procedure lives in the install guide; this page is the short version.

01

Check compatibility

Windows 10/11, Python 3.11+, WoW Classic 1.13 (client 2336×1323 tested). Read the compatibility matrix — untested means unsupported.

02

Install the package

After payment you receive a licence key and a versioned ZIP (bot + addon + config template) with a SHA-256 manifest to verify integrity.

03

Copy the addon

Drop the Casinobabe addon into your client's Interface\AddOns folder and activate it in the addon list at login.

04

Activate your licence

Your key activates on one machine. Activation is validated server-side: no secret lives in the package. A lost key can be re-sent by support.

05

Run the bot

One command starts the loop cast → bite → click → verify. F9 stops everything cleanly at any moment.

06

Watch the logs

Every cycle is logged (latency, result, cycle time). The same instruments feed the numbers we publish on this site.

Something jamming? Check known issues — and if it is not there, write to support@bot-wow.com.

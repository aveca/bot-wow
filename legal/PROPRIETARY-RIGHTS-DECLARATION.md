# BOT-WOW — déclaration de titularité et régime propriétaire

**Statut : déclaration du titulaire communiquée le 9 novembre 2026.**  
**Portée : code original du projet Casinababe / BOT-WOW uniquement.**

Le titulaire du projet a confirmé à l'équipe BOT-WOW qu'il détient les droits nécessaires sur le code original Casinababe qu'il a créé et qu'il autorise sa commercialisation et sa redistribution dans le cadre de BOT-WOW, sous un régime propriétaire et non open source.

Cette déclaration concerne uniquement les éléments originaux dont le titulaire détient effectivement les droits. Elle ne couvre pas les bibliothèques, polices, images, sons, textures, dépendances ou autres éléments tiers incorporés au produit.

## Régime de propriété

- Le code original couvert par cette déclaration est un logiciel propriétaire.
- Aucun droit de publication open source, de sous-licence générale ou de réutilisation publique n'est accordé par ce document.
- Tous les droits non expressément concédés restent réservés au titulaire.
- La distribution à un client final devra être encadrée par des conditions de licence client distinctes, affichées avant paiement et acceptées lors de l'achat.
- Ce document ne définit pas à lui seul le prix, la durée, le nombre de postes autorisés, le support, les mises à jour, les remboursements ou les garanties. Ces conditions doivent être cohérentes avec l'offre réellement livrée et les conditions commerciales validées.

## Limites et vérifications restantes

Cette déclaration ne régularise pas les composants tiers dont la provenance ou la licence reste non établie. En particulier, elle ne donne aucun droit supplémentaire sur :

- l'adaptation de **LibDBIcon-1.0** ;
- la texture **background.tga** ;
- toute autre œuvre tierce identifiée ultérieurement.

Ces composants doivent être remplacés par du code ou des ressources originaux, ou faire l'objet d'une autorisation/licence vérifiable, avant toute redistribution.

Le dépôt BOT-WOW ne contient pas nécessairement l'ensemble du code source de l'addon distribué. La présence de ce document ne remplace donc pas la vérification du dépôt source, de l'historique des contributeurs, du contenu exact du ZIP et de la correspondance entre le build et l'artefact R2.

## Traçabilité

Cette déclaration documentaire est fondée sur la confirmation explicite du titulaire reçue dans la conversation ChatGPT le **9 novembre 2026**. Elle constitue une trace de cette confirmation dans le dépôt ; elle ne remplace pas un contrat signé, une cession écrite provenant d'un tiers, ni un avis juridique.

**Conclusion opérationnelle :** le point « décision du titulaire sur le code original » peut passer à *déclaré par le titulaire* pour le périmètre décrit. Le paquet reste non certifié tant que les composants tiers non établis, le build exact, l'artefact de livraison et le parcours d'activation n'ont pas été vérifiés.

Which servers is it for?
Use BOT-WOW only on private servers whose published rules expressly permit fishing automation. Do not use it on Blizzard-operated services or on private servers that prohibit bots. The fishing assistant was tested on private servers. Do not use it on Blizzard Entertainment’s official servers.
What is BOT-WOW today?
BOT-WOW is currently accepting a Planner 9,00 € ou Studio 29,00 € one-time beta reservation for its Windows fishing assistant. This is a reservation, not an immediate software download or activated licence. The package is still undergoing final validation; if validated, delivery is manual by email. If we cannot deliver it, the reservation is fully refunded. The browser planner demo uses simulated data only.
Is the browser demo a free trial?
No. It is a standalone simulation for exploring the planner interface, not a trial of a downloadable client. It needs no account or installation and provides no game integration.

No. Planner is 9,00 EUR once and Studio is 29,00 EUR once. The key is emailed after payment is confirmed, and software that automates game control is not for sale.

Frequently asked questions

This page records current project status. For a factual question, contact support@bot-wow.com.

What is BOT-WOW today?
BOT-WOW is a historical project. No BOT-WOW product is currently offered for purchase. The only public interactive experience is the browser planner demo with simulated data; it does not connect to a game, read a game screen, send input or control a character.
Is the browser demo a free trial?
No. It is a standalone simulation for exploring the planner interface, not a trial of a downloadable client. It needs no account or installation and provides no game integration.
Can I buy or download the bot?
No. Checkout is closed. No client package, installation procedure, licence, activation or customer delivery is verified. Activation limits and terms are not confirmed. Do not send payment or follow historical purchase instructions.
What is the price?
There is no current selling price. €20 is a historical documented target only; it is not an offer or a request for payment.
Which payment methods are available?
None are currently available for BOT-WOW. Checkout is closed. Do not transfer money or use historical payment instructions.
Where is BOT-WOW intended to be used?
Intended for private servers, not official Blizzard servers. The rules of each server apply. No version is currently confirmed without a named server and a dated test record.
Can it fish, move a character or recover after death?
No game-integrated product is currently offered, so no runtime behaviour can be promised or verified for a customer. Older feature descriptions are historical project records, not current deliverables.
What about antivirus warnings or installation?
No executable or installation procedure is currently offered or verified. Do not install archived binaries or treat historical installation notes as current instructions.
Are updates or licence recovery available?
No current downloadable release or customer licence is offered. No update, activation-recovery or key-resend service is currently available.
Refunds?
No current sale is offered. The published refund policy is under owner review; this FAQ does not create additional refund terms. For an existing order, use the contact details in the published legal documents.

Demo — the fishing bot

The bot detects and memorises fishing spots, builds the oasis map, computes an optimised round and walks from one fishing spot to the next. This is the map and round-computation demonstration.

SIMULATED DATA. This map is a test fixture: the positions are synthetic and do not correspond to any real game session. The computation rules (risk weighting, availability, expected yield) are exactly the ones of the local program — an automated parity check compares both implementations at each build.

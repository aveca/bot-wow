Como funciona

Três passos, todos fora do processo do jogo. A demo mostra o planejador sem instalar nada.

1. Ler a janela

Um addon observa o estado do jogo. O cliente lê a janela como pixels, não a memória do processo.

2. Escolher a rodada

Os pontos salvos e o planejador propõem uma ordem. A mesma lógica roda na demo com dados simulados.

3. Clique como mensagem de janela

O clique vai para a janela, não para o processo. Uma parada de emergência continua armada.

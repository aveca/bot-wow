Release notes

Every significant fix comes with its measurement. The figures below come from real game sessions (Lushwater Oasis, client 2336×1323).

1.2.0 — current release

  • Spot memory, map, and versioned export / import.
  • Round planner: nearest neighbour + 2-opt, three modes (cautious / balanced / exploration).
  • Web demo of the map, with parity verified between the site computation and the local bot.
  • Versioned distribution package with a SHA-256 manifest.

1.1.0 — reliability fixes

  • Float detection recalibrated for day and night water (oasis water measures H45-62 by day and H78-95 by night).
  • Water texture discrimination (IQR ≤ 3): grass is textured, water is smooth.
  • Area floor (20 px²): the red-haired braid shares the float's colour signature and is no longer confused with it.
  • The "no water, no cast" guard (threshold 0.40).
  • Resilience: an isolated error (e.g. SetCursorPos refused) no longer kills the session.

1.0.0 — first public release

  • Full cycle: cast → bite detection → click → verification.
  • Instrumented, measured click latency (median 308 ms, p95 358 ms over 46 cycles).

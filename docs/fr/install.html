Installation

Le paquet contient l'addon, le bot et un gabarit de configuration. Aucune installation web n'est nécessaire : tout tourne en local.

1. Prérequis

  • Windows 10 ou 11 (64 bits).
  • Python 3.11 ou plus récent (python --version).
  • WoW Classic 1.13 (anniversary) lancé et connecté.
  • OpenCV et NumPy installés (pip install opencv-python-headless numpy) si vous n'utilisez pas le paquet fourni.

2. Décompression et copie de l'addon

  1. Décompressez casinobabe-fishing-<version>.zip.
  2. Copiez package/addon/Casinobabe dans <WoW>\Interface\AddOns\Casinobabe.
  3. Vérifiez que Casinobabe.toc est présent dans ce dossier : sans lui, le client ignore l'addon.

3. Configuration

Copiez package/config.example.json vers state/fishing-bot-config.json et ajustez :

  • clickAfterBiteMs — délai morsure → clic. Valeur mesurée recommandée : 450 (le taux de premier clic réussi passe de 18 % à 150 ms à 43 % à 450 ms, sur des échantillons de 17 à 23 morsures).
  • castKey — la touche liée à votre action de pêche (par défaut 2).
  • waterRatioMin — garde « pas d'eau, pas de lancer » (0,40).

4. Lancement

  1. python scripts/fishing_bot.py --cli
  2. Le bot attend la fenêtre du jeu (jusqu'à 5 minutes), puis vérifie que vous êtes bien en jeu.
  3. Arrêt propre : touche F9 sur la fenêtre du jeu. Le processus se termine et libère son verrou.

Ne lancez jamais deux instances : la seconde refuse de démarrer (verrou state/fishing-bot.pid).

5. Premier contrôle

Dans reports/fishing-bot-log.jsonl, vous devez voir CAST, puis CATCH_DETECTED et CLICK_BOBBER. Si le bot ne détecte rien, consultez la page problèmes connus.

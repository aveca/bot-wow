Installation

The package contains the addon, the bot and a configuration template. No web install is required: everything runs locally.

1. Prerequisites

  • Windows 10 or 11 (64-bit).
  • Python 3.11 or newer (python --version).
  • WoW Classic 1.13 (anniversary), running and connected.
  • OpenCV and NumPy (pip install opencv-python-headless numpy) if you do not use the provided package.

2. Unzip and copy the addon

  1. Unzip casinobabe-fishing-<version>.zip.
  2. Copy package/addon/Casinobabe to <WoW>\Interface\AddOns\Casinobabe.
  3. Make sure Casinobabe.toc sits in that folder: without it, the client ignores the addon.

3. Configuration

Copy package/config.example.json to state/fishing-bot-config.json and adjust:

  • clickAfterBiteMs — bite → click delay. Recommended measured value: 450 (first-click success went from 18% at 150 ms to 43% at 450 ms, over samples of 17 to 23 bites).
  • castKey — the key bound to your fishing action (default 2).
  • waterRatioMin — the "no water, no cast" guard (0.40).

4. First run

  1. python scripts/fishing_bot.py --cli
  2. The bot waits for the game window (up to 5 minutes), then checks you are actually in game.
  3. Clean stop: press F9 on the game window. The process exits and releases its lock.

Never run two instances: the second one refuses to start (state/fishing-bot.pid lock).

5. First check

In reports/fishing-bot-log.jsonl you should see CAST, then CATCH_DETECTED and CLICK_BOBBER. If the bot detects nothing, see the known issues page.

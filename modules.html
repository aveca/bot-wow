Recovery — the death chain

State machine fully specified (death detection → ghost confirmation → corpse navigation → resurrection). Being implemented behind a disabled-by-default flag.

Exists today
  • Death detection + dialog handling already tested (they stop the bot safely today)
Missing before "available"
  • Corpse-run chain end-to-end (transitions + in-game proof)

Until this lands, the product's behaviour after character death is: stop and ask a human.

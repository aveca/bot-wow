Commencer dès maintenant

Du téléchargement à la première prise. La procédure illustrée complète est dans le guide d'installation ; cette page en est la version courte.

01

Vérifiez la compatibilité

Windows 10/11, Python 3.11+, WoW Classic 1.13 (client 2336×1323 testé). Lisez la matrice de compatibilité — ce qui n'est pas testé n'est pas pris en charge.

02

Installez le paquet

Après le paiement, vous recevez une clé de licence et un ZIP versionné (bot + addon + gabarit de configuration) avec un manifeste SHA-256 pour vérifier l'intégrité.

03

Copiez l'addon

Déposez l'addon Casinobabe dans le dossier Interface\AddOns de votre client et activez-le dans la liste des addons à la connexion.

04

Activez votre licence

Votre clé s'active sur une machine. L'activation est validée côté serveur : aucun secret ne vit dans le paquet. Une clé perdue peut être renvoyée par le support.

05

Lancez le bot

Une commande démarre la boucle lancer → morsure → clic → vérification. F9 arrête tout proprement, à tout moment.

06

Suivez les journaux

Chaque cycle est journalisé (latence, résultat, temps de cycle). Les mêmes instruments alimentent les chiffres publiés sur ce site.

Un point qui coince ? Consultez les problèmes connus — et s'il n'y figure pas, écrivez à support@bot-wow.com.

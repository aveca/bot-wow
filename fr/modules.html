Registre des modules

Ce qui est réel, ce qui vient, ce qui n'arrivera pas.

Cette page est le contrat du produit. La pêche est disponible et couverte par la licence ; trois rôles sont en développement avec du code réel et testé ; quatre autres sont planifiés et clairement marqués « conception seulement ». Un statut ne vaut que par les tests derrière lui.

Registre v1.2.0 — 1 disponible · 3 en développement · 4 planifiés. Source de vérité : Casinobabe/scripts/botwow_modules.py, exporté vers assets/modules.json et vérifié à l'octet près à chaque build par npm test (modules-parity). L'export est déterministe : pas de dates inventées, pas de compteurs décoratifs.

Disponibleimplémenté · testé · preuves

Pêche — assistant + rondes optimisées

Le noyau qui fonctionne : détection mesurée du flotteur, mémoire persistante des spots, planificateur à parité vérifiée, mode arrière-plan, arrêt F9.

Livré et vérifié
  • Cycle lancer → touche → prise instrumenté (médiane mesurée 308 ms)
  • Mémoire persistante des spots (migrations, écritures atomiques, export/import)
  • Planificateur : plus proche voisin + 2-opt sur coûts mesurés ; 3 modes
  • Capture d'arrière-plan Windows (PrintWindow) et clics par messages
Limites
  • Clients Classic 1.13 uniquement, Windows 10/11
  • L'addon runtime observe l'état du jeu ; il ne simule jamais d'entrées

suites : python tests/fishing_bot_test.py · node tests/run-fishing-harness.mjs  |  fichiers : scripts/fishing_bot.py · scripts/fishing_memory.py

Assistant de pêche 1.2.0

Le seul runtime BOT-WOW qui existe sous forme de code, avec une suite de tests derrière : un client Windows qui lit la fenêtre du jeu (pixels) et envoie ses clics comme messages de fenêtre, plus un addon runtime WoW qui se contente d'observer l'état du jeu. Un produit, huit modules, un seul réel

BOT-WOW est un produit d'automatisation complet — pêche, navigation, inventaire, récupération, rotations de combat, scripting. Seul le noyau de pêche dispose aujourd'hui de code et de tests qui passent. Le reste est indiqué avec son statut réel, plutôt que disparaître en silence.

Destiné aux serveurs privés, pas aux serveurs officiels Blizzard. Les règles de chaque serveur s'appliquent. Aucune autorisation de Blizzard n'est revendiquée ni documentée. N'utilisez pas BOT-WOW avec les services exploités par Blizzard.

Lit des pixels, jamais le processus

Le client capture la fenêtre WoW avec l'API Windows PrintWindow, donc le jeu n'a pas besoin du focus. Les entrées sont envoyées comme messages de fenêtre. L'addon ne fait que lire l'état du jeu ; il ne simule jamais d'entrée.

Détection du flotteur par couleur, puis confirmation

Le flotteur est localisé sur la capture par un seuil HSV, et la touche est confirmée avant l'envoi du clic. La lecture mémoire et l'injection dans le processus du jeu sont des refus permanents — elles ne font pas partie de ce design.

Mémoire des spots et planificateur

Les spots de pêche sont persistés (schéma versionné, écritures atomiques, export/import), et le planificateur calcule des rondes par plus proche voisin puis 2-opt sur des legs mesurés, en trois modes. F9 arrête la session.

Paquet et prérequis

Reproduits depuis le fichier d'installation embarqué dans le paquet source. Rien n'est distribué aujourd'hui : c'est la spécification du build qui existe, pas un téléchargement disponible.

Prérequis
  • Windows 10 ou 11 (64 bits)
  • Python 3.11 ou plus récent (python --version)
  • WoW Classic (Era ou Anniversaire), avec le client lancé en jeu
  • Résolution native, client visible — le bot lit l'écran
Contenu du paquet
  • Addon runtime WoW, à copier dans \Interface\AddOns\Casinobabe
  • Scripts runtime Python (scripts/fishing_*.py)
  • config.example.json, INSTALL.md, MANIFEST.json, VERSION, notes de version
  • Point d'entrée documenté : python scripts\fishing_bot.py --cli · F9 arrête la session
Le raccourci de lancement exige en plus que Python soit disponible dans le PATH de la machine. Aucun installeur, aucune mise à jour automatique et aucune clé de licence ne font partie de l'état publié aujourd'hui.

Mesuré le 2026-11-08 avec le builder durci : deux builds consécutifs de la même source committée ont produit le même SHA-256, et les octets livrés sont identiques que le checkout soit en LF ou en CRLF. Le script de build amont ne reproduit pas, car il inscrit l'horloge de la machine dans le manifeste. L'empreinte canonique est l'identité de l'arborescence livrée, indépendante du conteneur ZIP. Cette empreinte remplace la mesure du 2026-11-07 (F8138F3C…) : le builder refuse désormais les liens symboliques, vérifie que chaque chemin réel reste sous la racine source, confronte la provenance CLI au checkout réel, et échoue faute de manifeste absent, illisible ou incomplet.

Questions auxquelles cette fiche répond

Puis-je télécharger l'assistant de pêche aujourd'hui ?
Non. Le paquet existe dans le dépôt source et peut y être reconstruit, mais aucun téléchargement n'est publié et aucun service de livraison n'est offert.
Lit-il mon personnage ou modifie-t-il le client du jeu ?
Non. Il capture la fenêtre du jeu (PrintWindow), analyse les pixels et envoie les clics comme messages de fenêtre. La lecture mémoire et l'injection de processus sont hors périmètre par conception.
Qu'est-ce qui est disponible, et qu'est-ce qui ne l'est pas ?
Le noyau de pêche dispose de code et de tests. Navigation, inventaire et récupération sont en développement. La couverture des clients, le follower, le grind et le scripting sont à l'état de conception. Le registre ci-dessus porte le statut exact de chacun.
Pourquoi un prix est affiché si rien n'est vendu ?
20,00 € est un ancien prix cible documenté, conservé pour la continuité du dossier du projet. Ce n'est pas une offre, et aucun paiement ne peut être lancé.
Quelles versions de serveur sont prises en charge ?
Le runtime vise WoW Classic Era (interface 20506). Aucun relevé de serveur daté n'est publié à ce jour : la page compatibilité reste la référence, et aucune version n'est confirmée.

Un producto, ocho módulos, uno de ellos real

BOT-WOW es un producto de automatización — pesca, navegación, inventario, recuperación, rotaciones de combate, scripts. Solo el núcleo de pesca tiene código y pruebas que pasan hoy. El resto figura con su estado real, en lugar de desaparecer en silencio.

Probado en condiciones reales. Sin afirmación sobre servidores oficiales. No se afirma ni documenta autorización de Blizzard. No use BOT-WOW con servicios operados por Blizzard.

Reads pixels, never the process

The client captures the WoW window with the Windows PrintWindow API, so the game does not need the focus. Inputs are sent as window messages. The addon only reads game state; it never simulates input.

Float detection by colour, then a confirmation

The float is located on the captured frame with an HSV threshold, and the bite is confirmed before the click is sent. Reading memory or injecting into the game process are permanent refusals — they are not part of this design.

Lugares y planificador

Fishing spots are persisted (versioned schema, atomic writes, export/import), and the planner computes rounds with nearest-neighbour plus 2-opt over measured legs, in three modes. F9 stops the run.

Package and requirements

Reproduced from the installation file shipped inside the source package. Nothing is distributed today: this is the specification of the build that exists, not an available download.

Requirements
  • Windows 10 or 11 (64-bit)
  • Python 3.11 or newer (python --version)
  • WoW Classic (Era or Anniversary), with the client running in game
  • Native resolution, client visible — the bot reads the screen
Package contents
  • WoW runtime addon, copied to \Interface\AddOns\Casinobabe
  • Python runtime scripts (scripts/fishing_*.py)
  • config.example.json, INSTALL.md, MANIFEST.json, VERSION, release notes
  • Documented entry point: python scripts\fishing_bot.py --cli · F9 stops the run
The launcher shortcut additionally requires Python to be available on the machine's PATH. No installer, no updater and no licence key are part of today's published state.

Questions this sheet answers

Can I download the Fishing Assistant today?
No. The package exists in the source repository and can be rebuilt from it, but no download is published and no delivery service is offered.
Does it read my character or modify the game client?
No. It captures the game window (PrintWindow), analyses the pixels, and sends clicks as window messages. Memory reading and process injection are out of scope by design.
What is available, and what is not?
The fishing core has code and tests. Navigation, inventory and recovery are in development. Client coverage, follower, grind and scripting are design only. The module ledger above carries the exact status of each.
¿Qué cubre el precio de 20 €?

Which server versions are supported?
The runtime targets WoW Classic Era (interface 20506). No dated server record is published yet, so the compatibility page stays the reference — and no version is confirmed.
